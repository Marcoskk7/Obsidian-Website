# 计算自注意力


这张图是自助意极致基准的一张图片。

其中，A和B同属于Badding的相量X1、X2。然后，X1和WQ、WK、WV相乘，得到Q、X1、Q、Key、X1、Value、X1、X2的流程也一样。

然后，相当于现在这个重命名为Q1、K1、B1。Q1和K1就相当于自己和自己的注意力形成，得到一个值，然后再除以√DK。这样，相对算出来自己的自助意力。

接着，它再和这个Q1、Q2第二个值进行一个形成，然后再除以这个DK，没有利的数值。最后，把它们进行Softmax,  再把得到的这个 softmax 比例值和 v 进行相乘再相加得到 z。

这张图图Q矩阵就是原始输入x乘以wq矩阵得到的，k矩阵就是原始的x乘以wk矩阵得到的。

之前的流程是只有一组 WQ、WK、WV，这叫单投注意力机制。如果对同一个 X 设计多组 WQ、WK、WB，那么就是多投注意力机制。

第一个注意的是，在这里它最后一步会得到像这张图中 Z0 到 Z7 一共8个矩阵。它们要先 concat 在一起，得到一个很长但是很矮的矩阵，向乘W0得到最终的 Z 向量。

# 位置编码

由于Transformer原本在不同位置的词是没有专门做区分的，所以我们要给它加上Positional Embedding，以便为位置进行编码。因为同一个字在不同的地方出现，应该代表的是不同的意思。 
![image.png](https://raw.githubusercontent.com/Marcoskk7/TyporaImageHosting/main/20260211111901643.png)


位置编码矩阵的计算公式中，Pos代表的是Position，也就是位置，而I代表的是编码的位置。可以看到，I不管取几，2I一定是偶数，2I+1一定是奇数。

因此，偶数列是Sine函数，而奇数列是用的Cos函数。 
此代表的 position 就是表示这是第几个词。 pos 是矩阵行数，比如 pos0, 就是矩阵的第0行，就是第 0 个词的位置编码向量

# Mask
## Pad Mask
为什么 ab 对 Pad 设置为 Mask，Mask 是个什么值，为什么pad 对 ab 又正常计算?
- 因为ab 对 Pad 的关注是没必要的，这个东西没有含义
- Mask 是-inf, 经过 Softmax 后无限趋近 0
- 因为 pad 对谁关注都无所谓，最后会裁剪为真实长度

# 完整计算流程

## Encoder部分

Encoder的部分很简单，就是像之前的课程一样，首先是拿到 x1、x2，然后给它们做一个位置编码，之后相加得到 x1、x2。接着，解一个注意力层，拿到 z1、z2。

然后，再把这几个 z1、z2 拼起来，用一个残差连接的方式和原始的 x 输入接到一起。接下来，只要再进行一个 layer norm，就可以得到新的 z1、z2。最后，接一个全连接层，再接一次这个 normalize和残差连接就可以了 
![image.png](https://raw.githubusercontent.com/Marcoskk7/TyporaImageHosting/main/20260211121523989.png)


 Decode部分其实和Encode部分的不同就是多了一个 Encode-Decode Attention 层，只不过 qkv 的设计不都是同一个 x 得到的
