
# 层次归一化vs批次归一化
layer normalization vs batch normalization
就是每个数据减去均值除以标准差

![image.png](https://raw.githubusercontent.com/Marcoskk7/TyporaImageHosting/main/20260205120909353.png)


batch norm 是把不同批次的统一位置进行归一化，但是显而易见，鸡和篮球不可以这样归一化

而 layer norm 是对同一批次的一行位置进行归一化
![image.png](https://raw.githubusercontent.com/Marcoskk7/TyporaImageHosting/main/20260205120243435.png)

# 优化器
优化器是用于进行梯度下降的，常见的有 SGD，Adam 等，其中 Adam 还会自适应更新 learning rate
