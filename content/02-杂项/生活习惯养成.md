# 身材管理

## 奶茶戒断习惯养成

> 打卡方式：在本文件顶部的 `milkTea` 列表里加一行今天的日期，格式 `"YYYY-MM-DD"`。

```dataviewjs
const currentYear = new Date().getFullYear();
const dates = dv.current().milkTea ?? [];

const calendarData = {
  year: currentYear,
  colors: {
    green: ["#9be9a8", "#40c463", "#30a14e", "#216e39"]
  },
  intensityScaleStart: 1,
  intensityScaleEnd: 1,
  entries: []
};

for (const d of dates) {
  const dateStr = typeof d === "string" ? d : d.toFormat("yyyy-MM-dd");
  if (dateStr.startsWith(`${currentYear}-`)) {
    calendarData.entries.push({ date: dateStr, intensity: 1 });
  }
}

renderHeatmapCalendar(this.container, calendarData);
```
